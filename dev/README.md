# Maintainer notes

This directory contains repository-only material for maintainers and automated
development tools. It is committed with the source, but deliberately excluded
from the Hex package and ExDoc output.

- [Testing](testing.md) describes the deterministic E2E harness and the opt-in
  live Shopify contract suite.
- [Shopify platform research and decisions](shopify-research.md) records the
  source material and tradeoffs behind the integration architecture.

The stable consumer-facing contract lives in the root README and the published
guides under `docs/`.
